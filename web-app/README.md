# 🗓️ Interactive Weekly Planner

A minimalist, high-precision digital planner inspired by classic paper weekly schedules. Designed for focus, clarity, and visual organization.

![Preview Placeholder](public/preview-screenshot.png) <!-- Note: Add a real screenshot here later! -->

## ✨ Key Features

### 🎨 Color-Blocked Scheduling
- **High-Resolution Grid**: Plan your day in 10-minute increments across a full 24-hour cycle.
- **Interactive "Painting"**: Select a marker and click-and-drag to color-block your schedule visually.
- **Dynamic Palette**: Add your own custom shades using the built-in color picker.

### 📝 Smart Task Management
- **Weekly Priorities & To-Dos**: Flexible lists that grow with your needs.
- **Visual Categorization**: Color-code individual tasks to match your schedule at a glance.
- **One-Click Clear**: Quickly reset your lists for a fresh start.

### 📱 Premium UX
- **Responsive "Floating Island"**: On mobile, your habits and priorities live in a sleek, centered overlay, leaving the schedule clutter-free.
- **Paper Aesthetic**: High-contrast typography and subtle ruled lines give the feel of a premium physical journal.
- **Local Persistence**: All your data is saved automatically to your browser—no login required.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React Hooks + LocalStorage API

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/weekly-planner.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. **Open in browser:** Visit [http://localhost:3000](http://localhost:3000)
